# One Line — Final Customer Website

This is a lean customer-facing replacement build.

## Included
- Home with category-first navigation
- Ready-made catalogue with Category / Subcategory / Size / Options filters
- No customer search box
- Separate T-shirt-only customizer
- Front / Back / Left sleeve / Right sleeve design views
- Sleeve view derived from the supplied side-sleeve reference image
- Exact selected colour applied to all T-shirt views with fabric shading retained
- Add text and uploaded images; drag, resize, rotate and delete layers
- Cloth type selection
- Printing type selection
- Sublimation automatically disabled on dark colours with explanatory message
- Ready-made product options and cart
- Simple order form stored locally as a front-end demo

## Structure
Only the customer files and assets required by this build are included. There are no framework dependencies, admin files, verification folders, or duplicated legacy CSS/JS bundles.

## Deployment
Upload the contents of this folder to any static host. `index.html` is the entry file.
